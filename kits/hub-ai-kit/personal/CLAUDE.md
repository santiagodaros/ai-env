# Skills personales
- Antes de afirmar límites, SKUs, GA/Preview o flags de CLI de Azure: usar azure-claim-check.
- Mails a cliente o management, informes y resúmenes ejecutivos: usar client-deliverables.
- Antes de entregar algo: usar deliverable-review.
- Relevamientos de inventario en Azure: usar azure-inventory-kql.
- Cuando se cierre una decisión importante o diga "checkpoint" o "retomemos": usar context-ledger.
- Español rioplatense. Sin nombres de cliente ni datos de tenant en archivos versionados.
